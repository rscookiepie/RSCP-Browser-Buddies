# 🐾 RSCP Browser Buddies

Interactive JavaScript companions for your webpages, created by **RSCookiePie**.
Browser Buddies is designed to bring animated pets, playful interactions, and
progression to the browser.

## ✨ Intended features

- Interactive companions with species, pet variants, and custom personalities.
- XP, levels, growth, achievements, accessories, and a shop.
- Animated Emberling fire, a Galaxy variant, Fire Trail, and Mini Nova effects.
- Random events, reactions, mouse trails, click effects, and visual improvements.
- Customisable controls, persistent progress, and Focus Mode.

See [FEATURES.md](FEATURES.md) for verification status and descriptions.

## 🚀 Installation and usage

There is nothing to install or execute yet. After the complete V4 source is
uploaded and reviewed, it should live at `src/browser-buddies-v4.js`.

The intended workflow is to review that JavaScript, open a trusted webpage,
open Developer Tools → Console, and execute the reviewed script. Do not paste
unknown code or bypass browser paste protections without understanding it.
Browser scripts execute with access to the page's content and browser APIs.

See the [usage guide](docs/USAGE.md) for the provisional workflow, controls,
storage questions, and limitations. Actual controls, cleanup, permissions, and
storage must be documented after source inspection. No browser is currently
listed as supported.
