# 🐾 RSCP Browser Buddies

Bring your browser to life!

Created by RSCookiePie | Powered by JavaScript

RSCP Browser Buddies is an interactive browser pet project that brings animated companions to your webpages.

Your buddy can interact with you, grow, develop its own personality, and unlock exciting features as you play.

---

# ✨ Features

- 🐾 Interactive browser companions
- 🎨 Different species and variants
- 🔥 Animated fire effects for Emberling pets
- 🌌 Galaxy-themed variants
- ⭐ XP, levels, growth, and achievements
- 🛍️ Accessories and in-game shop
- 🎲 Random events and interactive reactions
- 🖱️ Custom mouse trails and click effects
- 💾 Persistent pet progress
- 🎮 Customisable menus and controls
- 🎯 Focus Mode

Explore the full feature list in "FEATURES.md" (FEATURES.md).

---

# 🚀 How to use

Browser Buddies is designed as a JavaScript browser script.

Once the V4 source has been uploaded:

1. Open the V4 JavaScript file in this repository.
2. Review the code.
3. Copy the JavaScript.
4. On a trusted webpage, open your browser's Developer Tools and select Console.
5. Paste and execute the script.

Security note: Only run scripts you understand on websites you trust. Browser scripts can interact with webpage content.

Compatibility may vary by browser and device.
