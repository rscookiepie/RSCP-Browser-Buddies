# ✨ Feature guide

All features below are **planned / unverified**. The complete V4 JavaScript is
absent, so these descriptions explain intended behaviour rather than verified
controls or guarantees.

| Feature | Intended purpose | Status |
| --- | --- | --- |
| Interactive companions | Animated pets that react to user interaction | Unverified |
| Species and enhanced variants | Different pet appearances and personalities | Unverified |
| XP, levels, and growth | Progression as users interact with their pets | Unverified |
| Emberling fire | Animated fire effects for Emberling pets | Unverified |
| Galaxy variant | A galaxy-themed pet appearance | Unverified |
| Fire Trail | A fire-themed visual trail | Unverified |
| Mini Nova | A nova-themed visual effect | Unverified |
| Accessories | Customisation options for pets | Unverified |
| Achievements | Milestones for pet activities or progress | Unverified |
| Shop | Access to in-game items; mechanics and currency unknown | Unverified |
| Random events | Unexpected pet events and reactions | Unverified |
| Mouse trails and click effects | Visual responses to pointer activity | Unverified |
| Customisable menus and controls | Options for configuring the experience | Unverified |
| Focus Mode | A focus-oriented mode; exact behaviour unknown | Unverified |
| Persistent progress | Progress retained between sessions; storage mechanism unknown | Unverified |

## Verification before release

Review the uploaded source and test each feature before changing its status.
Document actual controls, storage keys, cleanup behaviour, external requests,
and browser results in the [usage guide](docs/USAGE.md). Record verified changes
in the [changelog](CHANGELOG.md); do not infer earlier-version behaviour from
these plans.
